# Week 5: Task List

Eight small exercises on slicing, slice assignment, and list comprehensions.

| File | Topic |
|------|-------|
| `task1_response_times.py` | Trim outliers and reverse with one slice |
| `task2_task_statuses.py` | Mutate a list with slice assignment |
| `task3_swap_coordinates.py` | Conditionally swap tuple values |
| `task4_temperature_conversion.py` | Filter and convert in one comprehension |
| `task5_matrix_operations.py` | Matrix diagonal and even-number flattening |
| `task6_moving_average.py` | Sliding-window averages |
| `task7_leaderboard.py` | Filter, sort, rank, and format players |
| `task8_odometer_segments.py` | Pair adjacent readings into segments |

Run any task with:

```bash
python3 task1_response_times.py
```
